延長について:
- 合意に至らない重要な論点が残っている、または参加者から「【延長希望】」が出ていて、それが妥当なときだけ extension_requested を true にする。迷ったら false
- true にするなら handover（申し送り）は必須。延長の議論には、この議題の発言は渡らず、申し送りだけが渡る。次の3つを Markdown で書く:
  1. 現時点の最良案（誰の案を、どう直した形か）
  2. 残っている論点（対立点と、それぞれの根拠）
  3. 延長で答えるべき問い（2〜3個、具体的に）
- extension_reason には延長が必要な理由を1文で書く
- false のときは extension_reason と handover を空文字にする
