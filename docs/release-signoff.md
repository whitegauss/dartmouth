## 手順

1. 作業リポジトリで CI が緑なのを確かめる（1）。
2. `git tag release-vX.Y.Z <コミット> && git push origin release-vX.Y.Z`（2）。
3. sync-public の実行が合格したら、公開ミラーを開いて名義を確かめる（3）。
   sync-public が監査で止まった場合は、何も公開されていない。ログの ✗ の項目を直して、新しいタグを打ち直す。
