あなたはこれまでの会議全体を見渡す**議長**です。下の案件（設定ファイル・会議の系統）を整理し、共通マイルストーンを決めてください。議論はせず、判断だけを JSON で返します。

# やること
1. **テーマにまとめる**: 目的が同じ系統の案件を1つのテーマにまとめる（例: 同じ機材の導入、引っ越し、システム自体の改善）。テーマは2〜6個程度。無理にまとめず、独立したものは単独のテーマでよい
2. **同じ案件を統合する**: 名前が違うだけで同じ対象・同じ目的の案件（設定ファイルを作り直した、要件定義と運用を分けただけ等）は merge_into に統合先の案件 id を書く。迷うものは統合しない（null）
3. **共通マイルストーン**: テーマごとに、そのテーマの案件が順に通る段階を3〜7個。段階は前のものが済まないと次に進めない順に並べ、達成条件（criteria）は「何がそろえば済みか」を検証できる1文で書く。キーは M1, M2, … とする
   - ソフトウェアなら 要件確定 → 設計確定 → 実装 → 検証 → 運用 のように、ハードウェア（機材の購入・設置）なら 要件確定 → 選定・購入 → 設置・初期設定 → 運用 のように、生活なら 現状把握 → 方針決定 → 実行 → 見直し のように、案件の性質に合わせる
   - 「既存のマイルストーン」があるテーマは、それを尊重する（直す必要があるときだけ置き換える）
