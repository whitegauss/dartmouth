# 比較実験の切替と停止

| 発生条件 | ランナーの動作 |
| --- | --- |
| 計測済みのセッション総トークンが360,000以上 | セッション中に一度だけ警告する |
| 計測済みのセッション総トークンが480,000以上 | セッションを ABORTED とし、進行中の独立回答を取り消す |
| HTTP 429、5xx、タイムアウト | 同じ発言を最大1回だけ再試行する。次の一時エラーで ABORTED とする |
| 利用枠の枯渇 | 許可された設定済みバックエンドに席ごとに最大1回切り替える。切替先がなければ ABORTED とする |
| Restricted の議題で別事業者への切替が必要 | 切替先に送信する前に ABORTED とする |
| Restricted の議題で議長が独立回答と異なる事業者 | モデル呼び出し前に ABORTED とする |
| その他のアダプタエラー | ABORTED とする |
| 応答の書式違反 | 3段の抽出を試みる。抽出できない場合は先頭400字に `[FORMAT_FALLBACK]` を付ける |

トークンは応答時に計上する。並列呼び出しでは計測前にすでに送信された呼び出しがあり、実消費が停止閾値を超えることがある。失敗・取消で使用量を取得できない場合は台帳に欠測を記録する。

JSON Lines の項目は席ID、モデル、切替理由、切替回数、プロンプトの SHA-256 に限る。モデルはアダプタが応答で返す識別子を優先する。モデル識別子の報告がない呼び出しは設定のモデル指定値を記録する。呼び出しの生のエラーやプロンプトは台帳とログに書かない。確認用の応答はローカル成果物に置く。
